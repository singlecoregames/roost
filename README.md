# Roost

iPhone·iPad용 무료 네이티브 Git 클라이언트. 클론·커밋·푸시·브랜치·머지 충돌 해결까지 앱 안에서 끝나고,
저장소가 iOS 파일 앱에 폴더로 나타나며, 게임 개발 파일(Aseprite·PSD·glTF·FBX·Ogg 등) 뷰어를 갖췄습니다.

A free native Git client for iPhone and iPad — clone, commit, push, branch, resolve merge conflicts, Files-app integration,
and previews for game-dev assets.
