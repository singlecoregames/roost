Support

During the beta, feedback and problem reports go through GitHub Issues.

Sending a problem report bundle

The most useful report is one made right when something looks wrong — sync paused, a save that never lands.

  1. In Roost: Settings → Support → Problem report
  2. Create bundle, then Share — mail, message, or save to Files
  3. Open a GitHub Issue with a line or two on what you were doing and what differed from what you expected, and attach the zip.

A bundle contains device model, iOS and app version, app and Files-extension logs, and sync status only. Repository names, paths, contents and credentials are never included, and the bundle leaves your device only when you share it. (Privacy policy)

Known issues (beta)

  • Files app sync may show "paused" or lag — run Recover under Settings → Advanced → Files app sync, then Reset if needed, and send a problem report from that moment.
  • .Trash may linger in the Files sync list (under investigation).
  • Leaving the app during a large branch switch can defer Files-app saves until you reopen the app.
  • Landscape is enabled only in viewers, diffs, commit detail and the merge editor.
  • The code index (find definitions/usages) is not in this build.

Frequently asked

  • Bitbucket repository list says "rejected" — use your Atlassian account email as the username and an API token (ATATT…) with read:workspace and read:repository scopes. The git push username is filled in automatically.
  • "SSH host key changed" warning — don't continue unless you know the server really rotated its key; only then choose "Replace the stored key and continue".
  • Edits from another app don't show in Changes — make sure you edited inside the Roost location in Files, then pull to refresh the Changes tab.
  • Data safety — this is a beta. Don't keep the only copy of a repository here; push important changes to a remote.

Feature requests and questions

Please open a GitHub Issue. The source repository is private; this repository hosts the site and the issue tracker.

지원

베타 기간 중 피드백과 문제 보고는 GitHub Issues로 받습니다.

문제 보고 번들 보내기

동기화가 멈추거나 저장이 밀리는 등 "뭔가 이상한" 순간에 바로 만들어 보내 주시면 가장 정확합니다.

  1. Roost 앱 → 설정 → 서포트 → 문제 보고
  2. 번들 만들기 → 잠시 뒤 공유 → 메일·메시지·파일로 보내거나 저장
  3. GitHub Issue를 열고 무엇을 하다가 무엇이 기대와 달랐는지 한두 줄 + 번들 zip 첨부

번들에는 기기 모델·iOS·앱 버전, 앱/파일 앱 확장 로그, 동기화 상태만 들어갑니다. 저장소 이름·경로·내용·인증 정보는 들어가지 않습니다. 번들은 사용자가 직접 공유할 때만 기기를 떠납니다. (개인정보 정책)

알려진 문제 (베타)

  • 파일 앱 동기화가 "일시 정지"로 보이거나 반영이 늦을 수 있음 — 설정 → 고급 → 파일 앱 동기화에서 복구를 실행하고, 그래도 안 되면 초기화. 그 순간의 문제 보고를 보내 주세요.
  • 파일 앱 동기화 목록에 .Trash가 계속 남을 수 있음 (조사 중).
  • 큰 브랜치 전환 중 앱을 벗어나면 파일 앱 저장이 앱을 다시 열 때까지 미뤄질 수 있음.
  • 가로 모드는 뷰어·diff·커밋 상세·머지 에디터에서만 켜집니다.
  • 코드 인덱스(정의·사용처 찾기)는 이 빌드에 없습니다.

자주 묻는 것

  • Bitbucket 저장소 목록이 "거부됨"으로 나와요 — 계정 사용자명에 Atlassian 계정 이메일을, 토큰은 API 토큰(ATATT…)에 read:workspace·read:repository 범위를 주세요. git 푸시용 사용자명은 앱이 자동으로 채웁니다.
  • SSH 호스트 키가 변경됐다는 경고 — 서버가 실제로 키를 바꾼 게 아니면 진행하지 마세요. 확인 후 "기존 키를 교체하고 계속"으로만 넘어갑니다.
  • 다른 앱에서 편집한 파일이 변경 사항에 안 보여요 — 파일 앱의 Roost 위치 안에서 편집했는지 확인하고, 변경 사항 탭을 당겨서 새로 고침하세요.
  • 데이터 안전 — 베타 빌드입니다. 유일한 사본인 저장소는 넣지 말고, 중요한 변경은 푸시로 원격에 두세요.
